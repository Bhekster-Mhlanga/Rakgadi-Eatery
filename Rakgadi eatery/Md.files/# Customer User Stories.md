# Customer User Stories

As a customer, I want to register an account so that I can order food online.

As a customer, I want to browse the menu so that I can choose meals.

As a customer, I want to add products to my cart so that I can order multiple items.

As a customer, I want to place orders online so that I can save time.

As a customer, I want to track my order so that I know when it is ready.

As a customer, I want QR code verification so that my order remains secure.

As a customer, I want to update my profile information so that my details stay current.

# Admin User Stories

As an administrator, I want to process orders so that customers receive food quickly.

As an administrator, I want to update order statuses so that customers receive live updates.

As an administrator, I want to manage products so that menu information remains accurate.

As an administrator, I want to generate reports so that I can monitor performance.

As an administrator, I want to validate QR codes and PINs so that only authorized customers collect orders.
